# 🌤️ Weather Forecast App

A Streamlit web app to get real-time weather information for any city in the world using the OpenWeatherMap API.

Features

Search weather by city name.

Displays temperature, weather condition, humidity, wind speed, and date & time.

Shows weather icon corresponding to current conditions.

Interactive and easy-to-use interface.

Installation

Clone the repository:

git clone https://github.com/<your-username>/weather-forecast-app.git
cd weather-forecast-app


Install dependencies:

pip install streamlit requests


Get an API key from OpenWeatherMap
 and replace API_KEY in the script.

Usage

Run the app:

streamlit run weather_forecast_app.py


Enter the city name in the input box.

The app will fetch and display the current weather information.
